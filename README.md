<h2>📁 Repository Structure</h2>

<p>
This repository is organized primarily by <b>topics</b>, following the progression of Python fundamentals 
(e.g., variables, conditionals, functions, iteration, strings, files, lists, etc.). Inside each topic folder, you may find a mix of:
</p>

<ul>
  <li>Jupyter notebooks (<code>.ipynb</code>)</li>
  <li>Assignments from courses or books</li>
  <li>Practice exercises</li>
  <li>Supporting files (such as text datasets)</li>
</ul>

<p>
At the beginning of the repository, the structure is strongly influenced by the 
<b>Python for Everybody (PY4E)</b> Coursera specialization, so some folders and files 
(e.g., <code>PY4E.ipynb</code>, <code>PY4E-Assignment</code>) correspond directly to that course.
</p>

<p>
As the repository evolves, additional materials from books such as 
<b>Learning Python</b> and <b>Think Python</b> are included within the same topic-based folders.
</p>

<p>
The naming of notebooks (for example, <code>PY4E.ipynb</code>) indicates the main source 
or reference used for those notes, allowing a quick identification of the origin of the content.
</p>
